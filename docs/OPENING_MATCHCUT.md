# 오프닝: 초고속 얼굴 정렬 매치컷 → 타이틀 → 벌스 시작

## 사용자 연출 의도

음악에서 프리코러스가 에너지를 끌어올리다가 큰 악센트로 코러스 또는 벌스에 진입하는 것처럼, **첫 9초 동안 태어날 때부터 첫돌 무렵까지** 수십 장의 사진이 같은 위치에서 점점 빠르게 교체됩니다. **9초 지점에서 음악 악센트에 맞춰 타이틀**을 내고, **12초 지점의 벌스에서 본편**을 시작합니다.

음악 제작과 최종 편집에서는 구조가 달라질 수 있으므로 현재의 초 단위는 **잠정값**입니다.

## 임시 타임코드 (30fps)

| 구간 | 프레임 | 연출 |
|---|---:|---|
| 00:00–00:09 | 0–269 | 얼굴 크기·양 눈 중심이 정렬된 사진 35~60장, 출생부터 현재, 컷 길이를 점진적으로 줄임 |
| 00:09–00:12 | 270–359 | 한 번의 악센트와 함께 빠르게 시선을 붙잡는 타이틀, 반복 플래시 사용 금지 |
| 00:12–00:18 | 360–539 | 벌스 분위기의 차분한 본편 첫 장면 (현재 합성 그래픽 데모) |
| 00:18 이후 | 이후 전체 4분 영화에 연결 예정 | 실영상·가족 음성·성장 타임라인 |

### 컷 가속

`video/src/opening/timing.ts`의 `distributeAcceleratingCuts()`는 전체 사진 수와 길이를 받아 각 컷에 **최소 2프레임**을 배정하고 초반보다 후반의 노출을 짧게 만듭니다. 30fps에서 2프레임은 약 67ms입니다. 너무 짧은 컷이 번쩍이는 화면으로 느껴지지 않도록 얼굴 위치, 노출, 색을 정규화하고 프리뷰를 반드시 검토합니다.

- 35~60장 권장(필수는 아님)
- **단조로운 동일 컷 길이가 아닌 가속 곡선**
- 전환 방식: 얼굴 모핑이 아닌 **기하학적 정렬 + 하드 컷**
- 아기 얼굴이 갑자기 왜곡되지 않도록 눈 위치/눈 사이 거리 중심으로 정렬
- 생후 초기에 메타데이터가 없으면 부모가 월령·순서 확인
- 여러 얼굴이 있을 경우 사진 자동 선택은 참고만 하고 사용자 검수
- 같은 위치에 얼굴이 유지되도록 **정렬한 정사각형(1080×1080) 사진을 화면 중앙에 고정**하고 양옆은 부드러운 배경으로 보완

## 수동 승인 및 실제 자료 연결

1. `sua-media`로 날짜 분석
2. `sua-face-align`으로 후보 PNG 생성
3. `output/faces/report.json`과 사진을 직접 보고 아이 얼굴 선택 상태·잘림 검수
4. 실제 성장 순서대로 `data/approved-matchcut.json`에 `approved_outputs` 목록 기록
5. `sua-matchcut` CLI로 로컬의 `video/public/media/matchcut/`에 **선택된 정렬본만 복사**
6. 생성한 `data/opening-props.json`을 Remotion `--props`로 전달

## 타임라인과 음악의 관계

음악은 사용자 직접 제작(Suno 등). 오프닝용 에너지가 실제로 올라가도록 인트로 아르페지오/리듬, 라이저, 타이틀 임팩트, 벌스의 다이내믹 다운을 설계합니다.

`docs/MUSIC_BRIEF.md`의 구조를 참고합니다. 실제 오디오 파일의 첫 비트·임팩트·벌스 시작 타임스탬프는 제작 후 사람 귀로 확인해 조정합니다.

**주의:** `video/src/opening/timing.ts`의 프레임 타이밍은 현재 상수입니다. 오디오에 맞춰 자동 비트 분석하여 동적으로 리타이밍하는 기능은 아직 구현되지 않았습니다.

## 구현과 한계

- `OpeningSequence`는 18초짜리 **합성 그래픽 데모**이며, 가족 사진이 없으면 실제 아이 얼굴을 표시하지 않습니다.
- `imagePaths` props에 승인한 정렬본 경로가 있으면 실제 사진을 재생합니다.
- `musicPath` props는 `video/public` 기준 상대 경로이며, 비어 있으면 무음입니다.
- 실제 4분 본편 연결과 가사/나레이션/비트 자동 배치는 아직 구현되지 않았습니다.
