# 오프닝 연출 확정안: 현재 → 탄생 역순 매치컷 → 탄생 영상 → 타이틀 → 본편

> 2026-10-26 기획 변경. 기존 '출생 → 현재' 매치컷과 '9초 매치컷 + 3초 타이틀'은 **이전 데모 사양**이며, 아래가 목표 연출이다. 현재 구현은 이 변경을 아직 모두 지원하지 않으므로 완성되었다고 간주하지 않는다.

## 의도

첫돌을 맞은 **현재의 수아**를 보여준 다음 사진의 시간축을 거꾸로 되감아 **태어난 순간**에 도착한다. 정지 사진에서 **실제 탄생 당시 동영상과 현장음**으로 전환해 시간을 멈춘다. 타이틀 `Sua, One Year.` 뒤에는 「네가 빛날 우주」의 완성 음원을 **파일 0초부터** 재생하며 출생부터 첫돌까지 순방향 본편을 시작한다.

이 구조는 노래 첫 가사 '처음 널 안던 날 / 내 두 팔이 참 서툴렀었지'와 연결된다. 원곡 가사·피치·템포를 수정하지 않는다.

## 목표 타임라인 (30fps, 잠정)

| 시간 | 프레임 | 화면 | 오디오 |
|---|---:|---|---|
| 00:00–00:01 | 0–29 | 가장 최근 정면 얼굴, 잠시 홀드 | 정적 또는 매우 약한 사운드 |
| 00:01–00:08 | 30–239 | 최근 → 신생아 **역순 얼굴 정렬 매치컷**, 점진적 가속 | 절제된 리버스 스웰/클릭 선택 |
| 00:08–00:12 | 240–359 | **실제 탄생 당시 동영상**, 4초(선택·승인 구간) | 가능하면 해당 영상의 현장음 |
| 00:12–00:15 | 360–449 | `Sua, One Year.` 타이틀, 절제된 페이드 | 현장음 정리, 필요 시 짧은 여운 |
| 00:15– | 450– | 출생 → 첫돌 **순방향** 본편 | 완성곡 **0:00부터 단 한 번 재생** |

구간은 편집 기준 초안이다. 탄생 영상의 의미 있는 장면에 따라 길이 조정 가능. 실제 가창 시작은 음원 자체의 인트로 길이에 따른다.

## 화면 편집 원칙

1. 정면 얼굴 사진 35–60장 중 촬영일이 확인되고 **보호자가 승인한 자료만** 사용한다.
2. 매치컷 입력 순서는 **촬영일 내림차순(현재 → 출생)**. 기존 도구가 입력 순서를 그대로 사용하므로 자동 역정렬된다고 가정하지 않는다.
3. 눈 위치와 얼굴 크기를 맞추되 얼굴 합성/모핑을 하지 않는다. 초반은 인식 가능한 홀드, 중후반은 점차 빠르게 전환한다.
4. 마지막 신생아 사진과 탄생 영상의 첫 프레임이 자연스럽게 이어지도록 선정한다. 연결이 어렵다면 **의도적인 하드컷과 사운드 변화**로 전환한다.
5. 탄생 영상은 개인 자료이므로 공개 저장소에 넣지 않는다. 실제 현장음 사용 여부도 보호자가 검토한다.
6. 탄생 영상의 마지막 컷 → 타이틀 → 본편 첫 가사 사이의 정서적 흐름을 우선한다.

## 사운드 원칙

- Suno로 별도 3분짜리 인트로 음악을 생성해 억지로 자르지 않는다.
- 기본안은 **리버스 매치컷 효과음 → 탄생 영상 현장음 → 짧은 타이틀 여운 → 원곡 시작**.
- 대안으로 원곡 반주의 일부를 모티프로 재구성할 수 있지만, **원곡과 무관한 게임풍/뮤지컬풍 인트로 음악은 지양**한다.
- 셔터음을 모든 사진에 넣지 않는다. 가속 효과음은 음량·빈도·청각 피로를 검수한다.
- 타이틀 효과음 잔향이 원곡의 첫 보컬을 가리지 않도록 정리한다.

## 구현 변경 요구사항 (미완료)

현재 `OpeningSequence`, `BirthdayFilm`, `sua-matchcut`, `sua-cold-open`, `sua-film`은 기존 **9초 매치컷 → 3초 타이틀 → 12초 노래 시작** 전제의 코드/문서가 남아 있을 수 있다. 다음 항목을 구현·테스트해야 한다.

- [ ] 매치컷의 **현재 → 과거** 승인 순서 검증 및 예제/CLI 문구 수정.
- [ ] 매치컷과 타이틀 사이에 **탄생 동영상 구간** 추가: 로컬 파일 경로, 원본 시작 오프셋, 길이, 크롭 정책.
- [ ] 탄생 동영상 **현장음 선택 재생**, 전후 페이드 및 음악과 겹치지 않는 믹싱.
- [ ] 타이밍을 1/8/12/15초 기준으로 재구성하되 구간 길이는 props에서 설정 가능하도록 설계.
- [ ] 전체 영상 `BirthdayFilm`의 콜드 오픈 길이와 곡 시작 오프셋을 **15초 기준**으로 연결. 전체 길이는 15초 + 음원 길이 + 별도 엔딩 카드 설정에 따라 산출.
- [ ] 합성 자료만 사용한 역순 사진·동영상·타이틀·음악 연결 테스트 및 30fps 경계 프레임 검사.
- [ ] README, TEMPLATE_SPEC, FULL_FILM, 예시 JSON, 테스트, CLI 도움말의 구식 시간/방향 설명 동기화.

**주의:** 이 문서 업데이트만으로 렌더링 동작이 변경되지는 않는다. 코드가 갱신되기 전에는 기존 데모가 9/12초 타임라인으로 렌더링될 수 있다.

## 개인정보와 검수

가족 얼굴·탄생 동영상·현장음·음원·렌더 결과는 **로컬에만 보관**하고 공개 GitHub/CI에 업로드하지 않는다. 얼굴 검출 실패, 날짜 오인, 프레임 점멸, 오디오 피크, 전환 지점의 블랙 프레임을 최종 상영 장비에서 직접 검수한다.
