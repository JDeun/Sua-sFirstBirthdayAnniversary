## 스타일

| 프리셋 | 활용 | 색상 | 전환/움직임 | 대략적 비중 |
|---|---|---|---|---|
| `cinematic` | 성장 본편, 가족 이야기 | 아이보리·차콜·세피아 | 소프트 디졸브·미세 팬/줌 | 70~80% |
| `scrapbook` | 월령별 일상 사진 | 크림·살구·세이지 | 종이 카드·약한 회전 | 15~25% |
| `variety` | 짧은 재미있는 장면 | 코발트·버터·코랄 | 리듬 컷/탄성 효과 | 5~10% |

기존 업체의 고유 로고·음악·레이아웃을 복제하지 않고 자체 구현합니다. 글꼴은 한국어 지원과 배포 라이선스를 검증한 후 확정합니다.

## 변경 핵심: 얼굴 매치컷은 반드시 맨 앞

이전 v0.1에서는 03:25경에 있던 매치컷을 **00:00으로 이동**했습니다. 오프닝에서 출생부터 현재까지 빠르게 훑은 뒤, 노래가 시작되면 탄생 장면으로 다시 돌아가 **천천히 감정적으로 회상**하는 구조입니다. 따라서 의도적인 시간 축 반복이지만, 인트로는 빠르고 본편은 느리므로 기능이 다릅니다.

초 단위는 실제 Suno 음악이 확정되기 전의 **작업용 기준**입니다. 음악 구조에 따라 각 장면의 길이를 조정합니다.

## 편집용 데이터 계약

- 시간은 정수 프레임으로 저장하며 `assetId`, `startFrame`, `durationFrames`, `cropMode`, `transition`, `caption`, `audioGain` 항목을 후속 스토리보드에서 사용합니다.
- `OpeningSequence`는 `imagePaths`, `musicPath` props로 재생합니다. `imagePaths`는 오직 **부모가 승인한 사진을 출생→현재 순서로** 입력합니다.
- 얼굴은 모핑하거나 AI로 합성하지 않고 정렬된 실사진으로 빠르게 하드 컷합니다.
- 배경음악은 Suno 등으로 사용자가 생성 후 로컬 파일로 전달합니다. 노래/타이틀 악센트는 가청 검사 후 프레임에 스냅합니다.
- 미검증 날짜는 월령이 확정된 것처럼 표기하지 않습니다.
- `storyboard.json`과 개별 음악 마커 문서는 추후 연결합니다. 지금은 v0.2 기획 및 18초 데모 단계입니다.

## 품질 검수

- 출력 목표: 1920×1080 / 30fps / H.264/AAC MP4. 현장 장비 규격 우선.
- 세로 영상, 카카오톡 저화질, HDR 영상은 개별 대응.
- 얼굴 점프/크롭 실패·검은 프레임·과도한 플래시 효과를 확인.
- 자막/사진 안전 여백 5%, 글꼴·음원 라이선스 확인.
- 개인 미디어는 로컬 처리, GitHub/공개 CI 업로드 금지.

## 데모 실행

~~~bash
cd video
npm install
npm run dev
npx remotion render src/index.ts OpeningSequence out/opening-demo.mp4
~~~

**OpeningSequence**는 18초 데모이고, 기존 세 프리셋은 각각 24초 데모입니다. 전체 4분 실영상은 추후 구현합니다.
