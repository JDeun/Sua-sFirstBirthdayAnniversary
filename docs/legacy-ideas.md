# 초기 설계에서 남길 아이디어

초기 스캐폴딩의 실행 코드는 현행 제작 경로에서 제외했다. 저장소의 이전 커밋 이력에서 원래 구현을 확인할 수 있다. 다음 원칙은 실제 제작 과정에도 유효하다.

- 원본을 유지하고 변환·정렬·누끼·색 보정 결과를 별도 작업 폴더에 기록한다.
- 날짜는 EXIF·QuickTime과 가족이 확인한 기념일을 함께 사용한다. 월 단위 기억과 정확한 날짜를 구분한다.
- 편집표에 장면마다 소스·사용 구간·역할·날짜 근거를 기록한다.
- 얼굴 매치컷은 눈·얼굴의 위치와 각도를 맞춘다. 자동 검출 결과를 확인하고 잘못된 방향·성인 얼굴·과한 크롭을 수동으로 고칠 수 있어야 한다.
- 음악 원본의 속도와 시작 시계를 유지하고, 전환은 측정한 박자와 실제 보컬 시각에 배치한다.
- 핵심 행동은 준비·동작·반응이 보이는 길이를 확보한다. 첫 순간과 일반적인 행동을 문구에서 구분한다.
- 프레임 수·디코딩·음량·영상 끝 화면·텍스트 영역을 검사한다. 연속 재생과 청취 검토도 진행한다.

현행 템플릿은 실제 제작에서 사용한 서사 장면·키네틱 타이포그래피·별·왕관·선물 그래픽과 이 검수 과정을 재사용할 수 있도록 구성한다. 개인의 이름·날짜·가사·사진 목록은 로컬 프로젝트 설정으로 전달한다.
